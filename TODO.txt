Актуальные показания для резервуаров мы берем в base vars

Параметр emulation берем из файла config.yaml у каждого резервуара отдельно.
При emulation == false
    [+] Отключаем tank_calc на этот резервуар
    [+] Записываем значения с датчиков в base_vars и ext_vars (в зависимости от ссылки в конфиге резервуара из reg_mappings)

При emulation == true
    [+] Не включаем modbus_worker при подключении этого порта
    [+] Включаем tank_calc и записываем в ext_vars данные из time_series.json (как сейчас и работает при запуске)
    [+] Запускаем tank_calc только на определенные резервуары, только там где emulation = true
    [ ] По-хорошему надо запускать tank_calc из modbus_worker после прочтения конфига


    Надо будет избавиться от tank_calc в том виде, в котором он сейчас есть. Расчеты для эмуляции надо будет брать из файла emulation.json,
    который будет лежать в папке самого tank, где и config.yaml. При этом, если нет файла и включена эмуляция, то ничего не делаем.
    По сути не будет никаких расчетов. Просто брать показания из файла и записывать по ссылке в base_vars и ext_vars
